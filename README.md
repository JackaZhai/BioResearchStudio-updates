# BioResearchStudio Updates

This public repository distributes BioResearchStudio release notes, installation packages, checksums, and signatures. It contains no BioResearchStudio source code, credentials, user data, or development history.

BioResearchStudio reads this repository's public [Releases](https://github.com/JackaZhai/BioResearchStudio-updates/releases) feed without requiring a GitHub account. Verify every downloaded package against the release's published checksum and signature before installation.
